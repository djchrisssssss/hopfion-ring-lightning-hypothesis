## 1. 摘要

球狀閃電形成於雷暴環境——本質上是湍流的。本計畫使用 The Well 的湍流資料集回答一個關鍵問題：

> **在什麼湍流條件下，拓撲保護的磁結構能夠存活？**

三個資料集——`turbulence_gravity_cooling`、`turbulent_radiative_layer_2D` 和 `turbulent_radiative_layer_3D`——模擬了帶有冷卻、重力和輻射過程的天文物理湍流。雖然並非大氣 MHD，但它們捕捉了控制球狀閃電環境的**可壓縮湍流與能量耗散的本質物理**。

本計畫：
1. **表徵渦旋穩定性**跨湍流態
2. **映射連貫結構存活的參數空間**
3. **訓練 ML 模型**從局域流場條件預測結構生命期
4. **為 Hopfion 假說的形成機制推導湍流約束**

這直接解決**問題 1（電阻衰減——方法 C：湍流抑制）**並強化假說的**第 7 章（環境條件）**。

## 4. 實施階段

### 階段 1：連貫結構普查（turbulence_gravity_cooling）

**目標**：系統性偵測並編目所有 2,700 條軌跡中的連貫渦旋結構，量測其生命期作為 (T_0, rho_0, Z) 的函數。

**方法**：

1. **渦旋辨識**使用多重準則：
   - **Q 準則**：Q = 0.5 * (|Omega|^2 - |S|^2)，渦旋核心在 Q > 0 處
   - **渦度密度**：xi = |omega|^2 = |curl(v)|^2，高渦度 = 強旋轉
   - **壓力極小值**：渦旋核心是局域壓力極小值

2. **連通分量標記**在閾值化 Q > Q_threshold 場上

3. **跨時間步的結構追蹤**：
   - 重疊追蹤：t+1 時刻的結構與 t 時刻匹配（空間重疊 > 50%）
   - 記錄：出生時間、死亡時間、生命期、峰值 Q、體積、質心軌跡

4. **27 參數網格的統計分析**：

   | 參數 | 預期效應 | 檢驗方法 |
   |------|---------|---------|
   | T_0（溫度） | 更高 T → 更劇烈湍流 → 更短生命期？或更高 T → 更多電離 → 更好的 MHD？ | 生命期 vs T_0 回歸 |
   | rho_0（密度） | 更高密度 → 更大慣性 → 更長結構持續性 | 生命期 vs rho_0 回歸 |
   | Z（金屬度/冷卻） | 更強冷卻 → 更快能量損失 → 更短生命期？或冷卻產生密度對比 → 穩定？ | 生命期 vs Z 回歸 |

5. **關鍵指標**：**結構存活函數** S(t) = P(生命期 > t)，對每個參數組合

**交付物**：~10,000+ 偵測結構的綜合目錄、跨參數空間的存活曲線。

**成功標準**：
- 結構偵測在已知渦旋環測試案例上驗證通過
- 生命期對至少一個參數有統計顯著的依賴性
- 清楚辨識最長壽結構的參數態

### 階段 2：冷卻-穩定性關係（turbulent_radiative_layer_2D/3D）

**目標**：確定輻射冷卻時間如何影響混合層介面處連貫結構的穩定性。

**方法**：

1. **先載入 2D 資料集**（6.9 GB — 快速迭代）
2. **混合層寬度演化**：
   - 定義混合層為 0.2 < density_normalized < 0.8 的區域
   - 追蹤每個冷卻時間 t_cool 的混合層寬度 h(t)
3. **Kelvin-Helmholtz 渦旋追蹤**：
   - KH 不穩定性在剪切介面產生渦旋捲——最接近嵌入環境空氣中 Hopfion 的流體力學類比
   - 追蹤個別 KH 渦旋：生命期、合併事件、耗散
4. **臨界冷卻時間**判定：
   - 繪製：vortex_lifetime vs t_cool
   - 辨識 t_cool_critical：
     - 快速冷卻（t_cool < t_critical）：結構被冷卻驅動的收縮摧毀
     - 慢速冷卻（t_cool > t_critical）：結構被湍流混合摧毀
   - **最佳結構存活態**接近 t_critical
5. **3D 驗證**：在 3D 資料上重複分析，比較 2D vs 3D
6. **映射至大氣條件**：
   - 球狀閃電形成於 T ~ 4200 K 表面、大氣壓力
   - 空氣在這些條件下的輻射冷卻時間：t_cool ~ 數秒
   - 與資料集的 t_cool 範圍比較，判定球狀閃電的位置

**交付物**：冷卻時間 vs 穩定性相圖、臨界 t_cool 辨識、大氣映射。

**成功標準**：
- t_cool 與結構生命期之間存在明確的非單調或閾值關係
- t_cool_critical 以不確定度範圍辨識
- 大氣球狀閃電條件放置在相圖上

### 階段 3：Hopfion-大氣介面的邊界層模型

**目標**：使用輻射混合層資料建模熱 Hopfion 核心與冷環境大氣之間的邊界。

**方法**：

直接解決 Hopfion 假說的**雙區模型**（問題 1，方法 D）：

```
[冷環境空氣, T ~ 300 K, 弱電離]
   |
   | <-- 混合層 / 邊界層
   |
[熱 Hopfion 核心, T ~ 10^4-10^5 K, 完全電離]
   |
   | <-- 混合層 / 邊界層
   |
[冷環境空氣]
```

1. **密度對比分析**：量測有效擴散係數作為密度比 chi 和 t_cool 的函數
2. **捲入率量測**：冷氣體被捲入熱相（及反向）的速率 v_e = dh/dt
3. **有效絕緣因子**：kappa_eff = (通過混合層的熱通量) / (無混合層的熱通量)
4. **壓力平衡檢驗**：驗證熱內部與冷外部可在壓力平衡下共存

**交付物**：有效擴散/絕緣係數、捲入率、邊界層模型參數。

**成功標準**：
- 至少一個冷卻態下 kappa_eff < 0.3（顯著絕緣）
- 捲入率 v_e < L_hopfion / tau_observed（邊界在觀測生命期內存活）
- 自洽的雙區模型參數辨識

### 階段 4：結構生命期 ML 預測器

**目標**：訓練 ML 模型從初始局域流場條件預測連貫結構生命期。

**方法**：

1. **訓練資料建構**（從階段 1 目錄）：
   - 輸入特徵：結構質心周圍的局域速度場、密度、壓力、溫度、Q 準則、渦度
   - 目標：結構生命期（時間步數）

2. **兩種模型方法**：
   - **a. The Well benchmark 模型上的回歸**：訓練 FNO/UNet，用自回歸展開量測結構持續性
   - **b. 直接生命期預測器**（輕量）：16^3 空間塊 → 3D CNN → GAP → MLP → 生命期

3. **特徵重要性分析**：SHAP 值或基於梯度的歸因
4. **外推至大氣 Hopfion 條件**：
   - 輸入球狀閃電形成區的估計大氣條件
   - 預測大氣湍流下的 Hopfion 生命期

**交付物**：訓練好的生命期預測器、特徵重要性分析、大氣生命期預測。

**成功標準**：
- 生命期預測器 R^2 > 0.6
- 前 3 個最重要特徵有物理可解釋性
- 大氣外推生命期在 0.1–100 s 範圍內（涵蓋觀測的 5–10 s）
