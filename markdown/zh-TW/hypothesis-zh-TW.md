## 第0章　序言：從閃電到環狀能量體

在自然界的極端條件中，球狀閃電（Ball Lightning）長久以來被視為最神秘且難以重現的電磁現象。

傳統理論無法充分解釋其能量密度、長達數秒的壽命，以及接近中性的浮力。（約束本身並不是謎：任何熱氣泡都由大氣壓力維持。）

本假說提出：所謂的球狀閃電應重新定義為 **Hopfion (Ring) Lightning**——由電漿與電流構成、磁力線彼此鏈結的電漿渦旋環體（plasma ring vortex）。

本假說提出：其結構由**磁場的拓撲量**——計算磁力線如何鏈結的磁螺旋度——以及**磁流自纏結結構**（self-linked magnetic current structure）所組織。這是否也能解釋其長達數秒的壽命，是核心的未解問題（第8A章）。

這種結構可視為自然界在電磁尺度上「吹出」的能量氣泡。

正如潛水員或海洋哺乳類在水中吐出的氣泡環能長時間保持形狀、緩慢上升、旋轉漂浮，電磁場亦能在特定條件下「吹出」一個由電漿與磁流構成的閉合環。

此環狀結構既非固體，也非瞬態電漿，而是被提出為一種**外邊界由周圍大氣壓力維持、內部結構由磁力線鏈結所組織的環狀場體**。

因此，本假說認為所謂的「球」是一個具環形內部結構的發光體，其圓形外觀來自環厚、電漿發光與周圍光暈（定量約束見附錄A）。

## 第1章　Ball Lightning 的再定義：Hopfion (Ring) Lightning

### 1.1　被誤解的外觀

觀測中所謂的「球狀」外型，被提出為厚環的投影，再經周圍熱氣體的光暈修圓，使觀者誤以為是實心球體。（v0.7 將修圓歸因於大氣散射；在多數報告的公尺級距離下，此效應可忽略——潔淨空氣在 10 m 處的 Rayleigh 光學厚度為 ~10⁻⁴。飽和的眼睛或相機產生的光暈溢散（blooming）也能把明亮影像修圓。）

非飽和的高速攝影應可辨識出環狀結構。熱輻射不具偏振，因此偏振無法揭示旋轉；不過光譜偏振測量（spectropolarimetry）可以偵測磁場（第10章）。

**幾何約束（v0.8 新增；附錄A）。** 對大半徑 R、小半徑 a、邊緣清晰的發光環面，在傾角 i 下的投影軸比為 q = (R cos i + a) / (R + a)。當 R ≥ a 時，隨機視角中最多 ~30% 給出 q ≥ 0.85；當 R > a 時，接近正面的視角會看到暗的中央孔洞。由於多數目擊者回報的是圓形物件，可見的環面必須是胖的（R ≤ a 才沒有中央孔洞，R ≈ 0.5 a 或更小才看起來近乎圓形），並嵌在與自身尺寸相當的光暈中。因此，此說法可檢驗的形式是：環形結構會出現在非飽和高速攝影或磁場量測中——而不一定出現在肉眼所見的輪廓上。

### 1.2　自然對應範例：氣泡環

潛水員、海豚或鯨魚吐出的氣泡環能在水中穩定上升並保持閉合形狀。其穩定機制來自環內外壓力差與流場自旋的平衡。

這種流體自組織的封閉環正是 Hopfion (Ring) Lightning 的自然類比，只是介質由水變為電磁場與電漿。

此類比是啟發性的。單純的渦環不帶螺旋度（其渦線是彼此不鏈結的圓）；氣泡環有表面張力界面，而氣體中的氣態電漿沒有；而且氣泡環在上升過程中會緩慢膨脹並破裂。

此類比也顯示電磁版本需要什麼。渦環之所以能持續存在，是因為在低黏滯（高雷諾數）流體中環量守恆。低黏滯在磁學上的對應是高電導率（高磁雷諾數）。大氣電漿是否滿足此條件，於第8A章定量檢驗；這是本假說最薄弱的一環。

### 1.3　核心觀點

因此，Ball Lightning 應重新命名與理解為：

**Hopfion (Ring) Lightning**——由磁力線纏結構成的拓撲能量環。

它被提出為大氣電漿在拓撲條件下形成的能量泡泡，而非傳統閃電放電的延伸或餘焰。

## 第2章　Hopfion (Ring) 結構：能量環的拓撲自封閉

### 2.1　理論背景

Hopfion 是一種以 Hopf 不變量分類其拓撲的場組態（field configuration）；Hopf 不變量由 Heinz Hopf（1931）[16] 針對三維球面至二維球面（S³ → S²）的連續映射提出。作為穩定的場論物件，hopfion 由 Faddeev 於 1970 年代提出，並由 Faddeev 與 Niemi（1997）[18] 提出為穩定的類結（knot-like）孤立子。

在物理學中，Hopfion 可理解為場線之間形成環狀鏈結的組態。當此組態出現在電漿中時，只要磁場持續凍結於高導電介質中，鏈結就會保持。此時它是一個**受拓撲約束的環狀能量體**。

**用語說明（v0.8）。** 本文中的「孤立子」（soliton）用法較寬鬆。在 Faddeev–Niemi 模型中，穩定性與偏好尺寸來自一個可規避 Derrick 尺度定理（Derrick's scaling theorem）的高階導數（類 Skyrme）項 [18, 39]。MHD 沒有這樣的項：螺旋度禁止解鏈，但不設定尺寸，而磁化電漿總能藉由膨脹降低能量（Arnold 不等式只在固定體積下為能量提供下界 [36]）。僅靠拓撲並不能約束：Ranada 的真空電磁結與 [20] 的鏈結光束都精確保持其 Hopf 指標，卻仍以光速擴散 [8, 20]。因此本文的「孤立子」意指「相干的自組織結構」，而非嚴格場論意義上的拓撲孤立子。

### 2.2　數學定義與拓撲荷

磁化電漿的關鍵拓撲量為**磁螺旋度**（magnetic helicity）：

```
H_m = ∫ (A · B) d³r
```

其中：
- **A** 為磁矢勢（vector potential）
- **B** = ∇ × A 為磁場（magnetic field）

此量由 Woltjer（1958）[21] 證明在理想 MHD 中守恆，Moffatt（1969）[22] 證明它量度磁力線的纏結與鏈結程度。對於由磁通為 Φᵢ 的細閉合磁通管構成的場 [22, 25]：

```
H_m = Σᵢ (Twᵢ + Wrᵢ) Φᵢ²  +  2 Σᵢ<ⱼ Lkᵢⱼ Φᵢ Φⱼ
```

其中 Lkᵢⱼ 為管 i 與管 j 的 Gauss 鏈結數，Twᵢ + Wrᵢ（扭轉加捲曲，twist plus writhe）為管 i 的自鏈結。因此，磁螺旋度是以磁通加權的鏈結計數，單位為 Wb²（T²·m⁴），它不是整數。

整數的 **Hopf 不變量** Q_H 只出現在由單位向量場 **n**: S³ → S² 建構的無因次場中，透過 Whitehead 積分得到 [17]；Ranada 的電磁結屬於此類，其螺旋度等於 Q_H 乘上一個固定的正規化常數 [8, 19]。v0.7 將 Q_H = H_m / (4π)² 套用於物理磁場，在因次上不一致，予以撤回。本文以 H_m 表示物理量，「Hopf 荷」只用於理想化的 Hopf 映射場。

另有兩項條件：

- ∫ A · B 只有在沒有磁力線穿越區域邊界時才具規範不變性（gauge invariance）。在開放大氣中，地磁場穿過該區域，有意義的量是**相對螺旋度**（relative helicity）[25]。
- H_m 只在理想 MHD 中嚴格守恆。在有限電阻率 η_e 下，它以 dH_m/dt = −2 η_e ∫ J · B d³r 衰減。因此，拓撲保護的前提是磁雷諾數夠大（第4、8A章）。

當 H_m 不為零且場被凍結時，磁力線彼此環繞，形成不經重聯就無法解開的組態，場在電漿內形成有結構的**「場泡泡」（field bubble）**。

### 2.3　穩定性要素（v0.8 修正）

v0.7 列出三個穩定性來源。每一項都只在以下受限形式中成立：

1. **拓撲約束**：只要場持續凍結於電漿中（Rm ≫ 1），鏈結的磁力線不經重聯就無法解鏈。這限制了場的弛豫方式——Taylor 弛豫在能量耗散的同時守恆螺旋度 [23, 24]——但它本身並不能阻止能量損失或膨脹。
2. **角動量**：旋轉結構只在黏滯與空氣動力阻力將角動量移除之前保有角動量。要讓場能組織流動，旋轉必須低於 Alfvén 速度（第8A.3節）。
3. **壓力平衡**：依磁維里定理（magnetic virial theorem），有限能量的電漿–場組態無法僅靠自身作用力達到平衡 [40]；它需要外部作用者。在此，該作用者是周圍大氣，透過邊界上的總壓力平衡 p_in + B²/2μ₀ = p_atm。在 50 mT 下，磁壓為大氣壓的 ~1%（電漿 β ≈ 100），因此設定外邊界的是大氣，而非磁場。它扮演的容器角色，相當於導電壁之於實驗室球馬克（spheromak）[38]。

氣泡環類比在此同樣成立：周圍水的壓力約束氣泡環，而其環流維持形狀。Hopfion (Ring) Lightning 被提出為電磁場的對應版本——場空間中的「氣泡環」。

### 2.4　已知對應系統

Hopfion 型結構已在多種體系中實現或模擬：

- 磁性多層膜中的自旋 hopfion [30]，以及立方手性磁體中的 hopfion 環 [32]（回顧：[35]）；
- Bose–Einstein 凝聚體中的結孤立子 [28, 29]；
- 手性液晶中的三維拓撲孤立子 [33, 34]；
- 結構光中的光學 skyrmionic hopfion [31]；
- 電阻性 MHD 模擬中自組織的結狀磁場 [27]；
- 實驗室球馬克——具有鏈結環向與極向磁通的緊湊電漿環，是現存最接近的電漿類比 [38]；
- 超導體中的拓撲磁通結構（僅有理論提案）。

在凝態、光學與凝聚體的例子中，拓撲由介質本身的剛性（交換作用、彈性、相位相干性）穩定，而大氣電漿缺乏這種剛性。這些系統顯示的是 hopfion 拓撲可在物理上實現，而不是它在空氣中穩定。

大氣條件下的 Hopfion (Ring) Lightning，將是這些結構的放電驅動、開放空氣中的近親——性質上最接近球馬克——一個以電磁場為流體、以拓撲為骨架的結構。

## 第3章　摘要：Hopfion (Ring) Lightning 假說核心

本文提出：Ball Lightning 是一種**磁力線彼此鏈結的緊湊環形電漿結構**——具非零磁螺旋度的 hopfion 型組態：

```
H_m = ∫ (A · B) d³r ≠ 0
```

並提出其圓形外觀來自透過自身光暈觀看的厚環面。

在此圖像中，大氣壓力約束此結構，螺旋度則組織其內部場，並約束其弛豫與分裂的方式。

v0.8 審查顯示，此拓撲約束只有在電漿的磁雷諾數夠大時才有效。對任何合理的球狀閃電溫度下的空氣電漿，磁雷諾數都小於 1（即使在最有利的情況下也 ≤ 0.4，4,200 K 時為 ~10⁻⁴），10 cm 結構的電阻衰減時間介於 ~10⁻⁷ s（4,200 K）與 ~10⁻⁴ s（20,000 K）之間（第8A章）。因此，解釋數秒的壽命需要拓撲以外的機制；這是本假說的核心未解問題。

此模型獨特且可檢驗的特徵是：環形內部結構、可量測的磁場及其衰減歷程，以及——若分裂期間 Rm ≫ 1——與螺旋度一致的分裂（第10章）。

## 第4章　核心命題與基本方程：MHD 下的 Hopfion (Ring) Lightning

在大氣壓下電漿高度碰撞，因此流體（MHD）描述是適當的。可壓縮電阻性 MHD 的基本方程為 [37]：

```
∇ · B = 0,        J = (∇ × B) / μ₀
∂ρ/∂t + ∇ · (ρv) = 0
ρ ( ∂v/∂t + v · ∇v ) = −∇p + J × B + ρν ∇²v + ρg
∂B/∂t = ∇ × (v × B) + η_m ∇²B        (uniform η_m)
```

並輔以包含歐姆加熱、熱傳導與輻射的能量方程。

其中：
- **η_m** = 1/(μ₀σ) 為磁擴散率（magnetic diffusivity；σ：電導率）
- **ν** 為動黏滯係數（kinematic viscosity；因此黏滯力密度為 ρν∇²v；v0.7 漏掉了因子 ρ）
- **μ₀** 為真空磁導率（magnetic permeability of free space）

v0.7 使用不可壓縮形式，並不適用於此問題：壓力平衡的 4,200 K 發光體，密度只有周圍空氣的 ~7%。對弱電離空氣（4,200 K 時電離分率 ~10⁻⁵），Ohm 定律還會多出 Hall 項與雙極（ambipolar）項。雙極項會增加耗散，Hall 項也不會消除耗散，因此兩者都無法挽救第8A章的壽命估算。

三個無因次量決定拓撲是否重要：

```
Rm  = v L / η_m          magnetic Reynolds number
S   = v_A L / η_m        Lundquist number   (v_A = B / √(μ₀ρ))
τ_η ≈ L² / η_m = μ₀ σ L²  resistive decay time
```

只有當 Rm 與 S 遠大於 1 時，磁力線才會凍結、螺旋度才會守恆。因此，「若磁力線形成閉合環且 H_m ≠ 0，則該結構受拓撲保護」這個命題只在 Rm ≫ 1 時成立，而約束來自大氣壓力，並非僅來自場的鏈結（第2.3節）。

## 第5章　Hopfion (Ring) Lightning 的拓撲結構特徵

1. 磁力線位於巢狀環面上並自我閉合（或稠密地覆蓋各環面）；
2. 在理想的 Hopf 荷為 1 的組態中，任兩條閉合磁力線恰好鏈結一次（Hopf 纖維化）；實際的電漿場只需帶有非零的淨螺旋度；
3. 發光體可能看似圓形，而核心磁結構為環形（附錄A）；
4. 內部電漿流同時具環向與螺旋分量。

在理想 MHD 中，H_m ≠ 0 的場無法經連續變形解開；改變其拓撲需要**拓撲變化**（如磁重聯）。這有兩項限定。第一，大部分磁能可以在不改變螺旋度的情況下耗散（Taylor 弛豫 [23, 24]）。第二，在電阻性電漿中，場也會在時間尺度 τ_η 上經擴散而衰減。非零螺旋度只在給定體積下保證磁能有下界（Arnold 不等式 [36]），而大氣並不會固定體積。

## 第6章　形成機制假說：從閃電到環場

### (A) 閃電觸發機制

1. 雲地回擊（峰值電流通常為 10⁴–10⁵ A；負極首次回擊的中位數 ~30 kA [41]）產生強磁場與剪切區；
2. 通道末端形成旋轉電漿渦（假設；尚未觀測到）；
3. 磁重聯分離出一個閉合的環狀場結構；
4. 若已注入淨螺旋度（第6A章），分離出的環帶有 H_m ≠ 0；
5. 環在螺旋度近乎不變的情況下，弛豫至最低能量（無力場）狀態，如同球馬克的形成 [23, 38]；之後由其殘餘角動量、浮力與任何電力決定其漂移與旋轉。

### (B) 自發拓撲生成（推測）

強電場梯度與地磁場或許能在沒有雷擊的情況下生成拓撲環。與宇宙弦形成、超導渦旋或液晶缺陷的比較只是鬆散的類比：那些結構是經由對稱性破缺相變形成，而大氣電漿沒有已知的對應過程。

本文未對此途徑提出機制或發生率估算；它屬推測性質，目前無法檢驗。

## 第6A章　螺旋度注入（v0.8 新增）

Taylor 弛豫守恆螺旋度，但不創造螺旋度，因此形成過程必須說明 H_m 從何而來。

- **直線通道**：直線閃電通道產生圓形（方位角向）磁力線，這些磁力線彼此不鏈結：H_m = 0。
- **需求（數量級）**：半徑 12.5 cm、B = 50 mT 的結構帶有磁通 Φ ≈ Bπr² ≈ 2.5 × 10⁻³ Wb，因此需要 H_m ~ Φ² ≈ 6 × 10⁻⁶ Wb²。
- **地磁途徑**：穿過通道的地磁場（B_g ≈ 50 µT）把通道的圓形磁力線變成螺旋線。由此產生的互螺旋度 ~2 Φ_axial Φ_azimuthal 為 ≈ 3 × 10⁻⁸ Wb²，其中 Φ_axial = B_g π r² ≈ 3.5 × 10⁻⁶ Wb（r = 15 cm），Φ_azimuthal ≈ (μ₀ I / 2π) ℓ ln(r_out/r_in) ≈ 4 × 10⁻³ Wb（I = 30 kA，ℓ = 0.3 m，r_out/r_in = 10）。即使將全部地磁場都取為沿通道方向，這仍小了約 200 倍。
- **尚未量化的候選途徑**：非平面（捲曲或扭轉）通道的自螺旋度；相繼回擊或分支之間的互鏈結；對湍流螺旋度的選擇性捕獲。

**狀態：未解。** 螺旋度來源是因果鏈中必要的一環，必須先將其量化，才能稱此形成機制具有物理基礎。（腳本：[`analysis/self_consistency.py`](../../analysis/self_consistency.py)。）

## 第8章　壽命：拓撲約束的能量泡泡？

空氣中的非平衡放電電漿會在毫秒內復合。相較之下，處於局部熱平衡的熱氣體球只要保持高溫就會持續發光：單靠熱傳導，要經過秒量級的時間才能冷卻一個 25 cm 的球，較快的損失途徑是浮升與混合（發光體在 ~0.1 s 內即上升相當於自身直徑的距離；第8A.2節）。球狀閃電據報可持續數秒。任何結構的壽命都是其儲存能量除以總損失率：

```
τ ≈ E_stored / P_loss
P_loss = P_Ohmic + P_radiation + P_conduction + P_convection,    P_Ohmic = ∫ J²/σ d³r
```

**修正。** v0.7 寫作 τ ∝ L / P_dissipation，其中 L ≈ MR²ω 為角動量。此比值的單位是 s²，而非 s；而引用的「L ≈ 10⁻³ kg·m²/s ⇒ τ ≈ 5–10 s」並未給出 P_dissipation 的值。兩者均予撤回。此外，對質量 0.7 g、半徑 10 cm 的物體，L ≈ 10⁻³ kg·m²/s 意味著邊緣速度只有 ~15 m/s，與 v0.7 自己 500–2,000 m/s 的旋轉預測矛盾。

對磁結構本身而言，相關的時間是電阻衰減時間 τ_η ≈ μ₀σL²。第8A章對其進行估算：對大氣電漿而言，它比觀測到的壽命短了許多個數量級。拓撲結構能否充分抑制徑向擴散以彌補此差距——即本章原本的直覺——是本假說的未解問題。

## 第8A章　定量自洽性檢驗（v0.8 新增）

參考發光體：直徑 25 cm（V = 8.2 × 10⁻³ m³），溫度 4,200 K（v0.7 採用的值；針對記錄最完整之事件的光譜研究，由 Si I 與 Fe I 譜線得到 ~4,300–4,600 K，由 O I 譜線得到 ~8,750 K [46]），壓力 1 atm。壓力平衡給出密度 ~0.08 kg/m³（為周圍空氣的 6–7%，取決於 O₂ 的解離程度），質量 ~0.6–0.7 g。以下結論均不取決於確切溫度：8A.1 的表格涵蓋 3,000–20,000 K。本章大部分數字可由 [`analysis/self_consistency.py`](../../analysis/self_consistency.py) 重現。

### 8A.1　電阻壽命與磁雷諾數

| 電漿狀態 | 電導率 σ (S/m) | η_m = 1/(μ₀σ) (m²/s) | L = 0.1 m 時的 τ_η |
|---|---|---|---|
| 3,000 K 平衡態空氣（估算） | ~0.4 | ~2 × 10⁶ | ~5 × 10⁻⁹ s |
| 4,200 K 平衡態空氣（估算；電離度 ~10⁻⁵） | ~7 | ~1 × 10⁵ | ~1 × 10⁻⁷ s |
| 6,000 K 平衡態空氣（估算） | ~4 × 10² | ~2 × 10³ | ~5 × 10⁻⁶ s |
| 10,000 K 平衡態空氣（數量級；參見 [42]） | ~3 × 10³ | ~3 × 10² | ~4 × 10⁻⁵ s |
| 20,000 K 平衡態空氣（數量級；參見 [42]） | ~1 × 10⁴ | ~80 | ~1 × 10⁻⁴ s |
| **τ_η = 5 s 所需** | **~4 × 10⁸** | **~2 × 10⁻³** | **5 s** |

3,000–6,000 K 各列為數量級估算（Saha 平衡，NO 占分子的 ~3%，外加 1 ppm 鈉；電子–中性粒子碰撞截面 ~10⁻¹⁹ m²）。[1] 中所見的那類土壤蒸氣（Si、Fe、Ca）可能把 ~4,000 K 時的 σ 提高到 ~10² S/m，而該溫度下即使完全電離也無法超過 Spitzer 值 ~10³ S/m [43]；兩者都不改變結論。

粗略估算 τ_η ≈ μ₀σL² 是寬鬆的。半徑 a 的導電球，其最低自由衰減模（極向 ka = π，環向 ka ≈ 4.49）以 τ = μ₀σa²/(ka)² 衰減，磁能與螺旋度則在一半的時間內衰減至 1/e。對 a = 12.5 cm，這使上表的衰減時間縮短 ~13–26 倍，並使 5 s 能量壽命所需的電導率提高到 ~5 × 10⁹–1 × 10¹⁰ S/m。**因此，所需電導率為銅的 7 倍（粗略估算）至 ~170 倍（最低衰減模）**（銅為 6 × 10⁷ S/m）。作為比較，在直徑 25 cm 的實心銅球中，內部磁能在 30–60 ms 內即衰減至 1/e。

取 L = 0.1 m，即使 v = 300 m/s（受 Alfvén 速度限制的上限，8A.3）並取最有利的 η_m ≈ 80 m²/s，磁雷諾數 Rm = vL/η_m 最多也只有 ~0.4。在 4,200 K 時則為 ≲ 3 × 10⁻⁴。因此，場並未凍結於電漿中，螺旋度在觀測到的壽命內不守恆，**拓撲保護不起作用**。

場也無法如 v0.7 第8章所暗示的那樣充當隔熱層（「拓撲結構抑制徑向擴散」）。在 10–100 mT 下，電子 Hall 參數 ω_ce/ν_en 只有 ~0.03–0.3，離子的磁化程度更是低得多，而中性氣體——在 4,200 K 時占粒子的 99.999%——完全感受不到磁場。

兩條誘人的出路都行不通：

- **更熱的核心。** Spitzer 電阻率隨 T^(−3/2) 下降 [43]，但即使是完全電離的 10⁵ K（8.6 eV）核心，也只給出 η_m ≈ 16 m²/s 與 τ_η ≈ 0.6 ms。這樣的核心在 1 atm 下也會嚴重過壓或極度稀薄，並會強烈輻射。
- **「螺旋度比能量長壽」。** 對單一無力場（Beltrami）模 ∇ × B = αB，磁能與螺旋度以相同速率 2η_m α² 衰減。只有在多尺度（湍流）場中，螺旋度才會比能量持久，而且那是藉由把能量轉移到大尺度，而非停止衰減。

### 8A.2　能量預算

| 成分 | 估算值 | 備註 |
|---|---|---|
| 磁能，(B²/2μ₀)·V | 0.33 J（10 mT）、8 J（50 mT）、33 J（100 mT） | 以磁能形式儲存 8 kJ 需要 B ≈ 1.6 T，即 ~10 atm 的磁壓。無論拓撲為何，維里定理將 1 atm 在此體積中所能容納的磁能上限定為 3p_atm V ≈ 2.5 kJ |
| 動能（旋轉），½Mv² | v = 30–300 m/s 時為 0.3–33 J | v0.7 的 500–2,000 m/s 會給出 86–1,400 J，但不自洽（8A.3） |
| 熱能，高於環境的顯焓 | ~3 kJ | c_p ≈ 1.25 kJ·kg⁻¹·K⁻¹，ΔT ≈ 3,900 K |
| 化學能，O₂ 解離 | ≤ ~2.5 kJ | 復合時釋放；上限假設完全解離 |
| **總計** | **~5–6 kJ，其中磁能 < 1%** | |

基於調查的估算將最可能能量定在 ~6–7 kJ [45]。若這個量級的能量屬實，磁場就不可能是能量儲存庫；它至多只能塑形或隔絕以熱能或化學能形式儲存的能量。

熱能儲存帶來它自己的問題：**浮力**。壓力平衡的 4,200 K 發光體密度為周圍的 6–7%，會以 ~1.7–2.5 m/s 上升（阻力係數 1–0.5），~0.1 s 內就移動相當於自身直徑的距離，然而約半數報告描述的是以水平為主的運動 [4]。在近乎均勻的地磁場中，孤立的電流系統只受力矩而不受淨力，因此磁場無法抵消浮力；必須由環境電場中的淨電荷，或未納入模型的質量負載（例如源自土壤的粒子）來抵消。

### 8A.3　旋轉與磁場的一致性

在 1 atm 下，離子因碰撞而與中性氣體鎖定，因此 Alfvén 速度須使用總密度：對 10、50 與 100 mT，v_A = B/√(μ₀ρ) ≈ 31、154 與 308 m/s。

v0.7 預測的 500–2,000 m/s 旋轉速度：

- 為超 Alfvén 速度，因此流動會捲繞並主導磁場，而非受磁場組織；
- 在周圍空氣中超過音速（343 m/s），因此應輻射強烈的聲學噪音，然而球狀閃電多被描述為幾乎無聲；
- 無法被約束：其離心壓力 ρv² = 0.2–3.3 atm 超過 100 mT 下的磁壓（0.04 atm）5–85 倍；要達到平衡需要 B ≈ 0.23–0.92 T。（若改與磁張力 B²/μ₀ 比較——即與 v ≲ v_A 等價的判據——則為 ~3–40 倍，B ≈ 0.16–0.65 T；無論哪種比較，磁場都無法約束此流動。）

因此，該預測改為 v ≲ v_A（第10章）。

氣泡環類比給出更嚴格的限制。若部分內部流動是極向環流——即形成煙圈或氣泡環的那種流動——環會沿其軸以與該環流相當的速度自我推進：標準渦環速度 U = (Γ/4πR)[ln(8R/a) − ¼]，取 Γ = 2πa·v，對大半徑 7.5 cm、核心半徑 5 cm 的環給出 U ≈ 0.7 v（Hill 球形渦給出 ⅔）。因此，典型的數 m/s 漂移速度 [4, 45] 將極向環流限制在數 m/s。

### 8A.4　與實驗室球馬克的比較

球馬克是實驗室中的緊湊環（compact torus），具有鏈結的環向與極向磁通。它們經由螺旋度注入形成並弛豫至 Taylor 態——是所提結構現存最接近的類比 [38]。它們遠比任何合理的大氣電漿熱（電子溫度為數十至數百 eV，此處則為 ~0.4 eV），運作密度約 10¹⁹–10²⁰ m⁻³，置於導電的磁通守恆器內，卻仍在毫秒內衰減 [38]。

由於電阻衰減時間與 T^(3/2) 成正比，~0.4 eV 的大氣結構應衰減得更快，而非更慢。本假說的任何可行版本，都必須解釋它為何能比實驗室對應物長壽三個或更多數量級。

### 8A.5　v0.8 審查後的狀態

以 v0.7 的形式——「僅靠拓撲即可提供數秒的穩定性」——本假說未能通過定量自洽性檢驗：電阻衰減時間比觀測壽命短四到九個數量級（粗略估算，視溫度而定）。它只能以修正後的形式存續。候選方向如下，皆未解決：

1. **拓撲組織、非磁能供能。** 螺旋度在最初一毫秒或更短的時間內塑造結構，而熱能或化學能儲存庫為長壽命的發光供能（例如 [14] 所述的源自土壤之粒子的氧化；[1] 中觀測到土壤元素譜線）。檢驗：磁場應在形成後 ≲1 ms 內衰減，遠早於發光消退。
2. **非 MHD 電流載體。** 由帶電氣膠或奈米粒子攜帶的電流，其輸運方式與自由電子不同。屬推測；尚無估算。
3. **外部維持。** 能量或電流由周圍雷暴電場持續供給，如電荷沉積模型 [15]。此時結構並非自足，其壽命應與環境電場相關。即使只是在 25 cm 的發光體中對抗歐姆損失維持 10 mT，也需要 ~10⁴–10⁸ W（從 20,000 K 到 4,200 K）。
4. **流體力學環。** 浮升的熱氣團（thermal）在上升數個直徑的距離內就會自然捲成渦環。因此，環狀形態可能純粹出於流體力學原因而產生，磁螺旋度為零——與氣泡環直覺一致，但與拓撲保護不符，且與水平運動的報告有所衝突。可在實驗室電漿體中檢驗。

每個方向都會改變本假說對能量與壽命的主張，因此它們被列為未解問題，而非假說的一部分。

| 沿導體運動 | 無驅動力 | 需要淨電荷（鏡像電荷吸引）——這是額外假設，不屬於 MHD 圖像。單獨的磁偶極若在移動或衰減，會被非鐵磁性導體中的渦電流排斥，而非吸引 |

## 第10章　理論可證偽預測：Hopfion (Ring) Lightning 的實驗特徵

1. **磁場特徵（最強且最便宜的檢驗）。** 內部磁場 10–100 mT（假設的量級，非推導所得）。其外部（極向）部分大致以偶極方式衰減：若半徑 12.5 cm 發光體的表面為 50 mT，則 1 m 處為 ~100 µT，2 m 處為 ~12 µT；對 10–100 mT，10 m 處為 ~20–200 nT。這在近距離下與地磁場相當或更大，可用磁通閘磁力計（fluxgate magnetometer）量測，且作為持續數秒的準靜態訊號，可與回擊的 µs–ms 瞬態區分。（純環向分量從外部看不到。）除非第8A章的未解問題獲得解決，磁場應在 ≲1 ms 內衰減；**磁場衰減相對於發光的時序是最犀利的檢驗。** 持續數秒的磁場將推翻標準電阻性 MHD 的預期；若在儀器完善的自然事件附近量測不到磁場，將排除磁結構化的球狀閃電模型，包括本模型。實驗室類比（水放電電漿體 [51]、矽放電火球 [44]、微波火球 [52]）只能檢驗這類電漿體是否帶有磁場。
2. **旋轉與偏振。** 若存在旋轉且受磁場組織，它應為次 Alfvén 速度：對 10–100 mT，v ≲ v_A ≈ 30–300 m/s。由此產生的都卜勒位移（600 nm 處 ≲ 6 × 10⁻⁴ nm）低於 4,000 K、1 atm 下發射譜線的熱都卜勒寬度與壓力寬度（數 × 10⁻³ nm），因此盤面積分的「旋轉展寬」不是可用的特徵。旋轉只能以空間解析的邊緣對邊緣都卜勒位移（解析力 ≳ 10⁵，實際上只適用於實驗室類比）或高速攝影中的非軸對稱特徵來偵測——一個繞自身軸旋轉、軸對稱且均勻發光的環面看起來是靜止的。磁場本身原則上可用光譜方法量測：Zeeman 分裂（10–100 mT 下為 ~2 × 10⁻⁴ 至 2 × 10⁻³ nm）無法解析，但視線方向的淨磁場會在譜線翼產生圓偏振（Stokes V），可用光譜偏振測量偵測。純環向場在未解析的觀測中大多會相互抵消。
3. **壽命–尺寸關係。** 若壽命受電阻衰減限制，則在固定溫度下 τ ∝ L²（τ_η = μ₀σL²）。壽命對直徑的調查數據可檢驗此尺度關係，儘管絕對值（第8A章）已相差許多個數量級。
4. **形狀統計。** 若發光體是 R ≳ a 的環面，高速影像從多數視角應顯示拉長的輪廓（軸比 < 0.85），接近正面時則中央變暗（附錄A）。從許多角度拍到的影像若都一致呈圓形，將要求是光暈內的胖環面，或證偽「可見環面」版本。
5. **能量。** 在 10–100 mT 下，25 cm 發光體的磁能 ≤ ~33 J。若基於損害的千焦耳或更高的能量估算獲得證實，磁場就不可能是主要儲存庫（第8A.2節）。
6. **旋向。** 若分裂期間 Rm ≫ 1（參見 8A.1），螺旋度的正負號應保持；若一對子結構旋向相反，將與螺旋度守恆的分裂相矛盾。

## 第11章　結語：宇宙的電磁泡泡 Hopfion (Ring) Lightning 的科學定位

本假說的直覺起點，是「大氣靜電網在自身場中吹出一個 Hopfion 環泡泡」。

本假說提出：發光體的結構由**磁場的拓撲鏈結**所組織，並由周圍大氣維持在原位。v0.8 審查顯示，此鏈結本身無法解釋長達數秒的壽命（第8A章）；這是未來版本必須解決的問題。

- 若假說成立，Hopfion (Ring) Lightning 將是一種磁力線彼此鏈結、自由漂浮的大氣電漿結構——實驗室球馬克在自然界的近親。地球大氣中尚未確認存在這樣的結構。（帶螺旋度的宏觀結構確實存在於其他地方：實驗室球馬克 [38]，以及曾被詮釋為類球馬克結構的行星際磁雲 [55]。因此撤回 v0.7「首個在自然界觀測到的宏觀拓撲孤立子」的說法。）
- 它將在 **MHD、拓撲場論與大氣電漿物理**之間建立新橋樑。
- 它將提供一個**受拓撲約束之能量自組織**的自然實例。
- 它凸顯一種「場吹泡泡」的自然圖像——能量以場的形式自我組織，並具暫態的持續性。

---

*本假說框架設計為可證偽、以物理為基礎的理論提案，待實驗驗證。v0.8 明確陳述其核心定量問題（第8A章），使其能被檢驗，並在必要時被證偽。*

## 先行研究與學術脈絡

本假說建立在球狀閃電拓撲模型的成熟學術脈絡之上，特別是 **A. F. Ranada 與 J. L. Trueba**（1989–2000）[8–12] 所開創的電磁結框架。其基礎貢獻包括：

- 證明 Maxwell 方程具有以 Hopf 指標為特徵的拓撲解 [8, 9]
- 提出球狀閃電為拓撲穩定的電磁結 [10]
- 發展鏈結流束模型，解釋壽命、能量與輻射功率 [11]
- 透過 Taylor 弛豫、Alfven 條件與螺旋度守恆分析穩定性 [12]

本工作在 Ranada-Trueba 框架基礎上的延伸貢獻：

1. **將 Ranada–Trueba 電磁結——已由 Hopf 指標刻畫 [8, 9]——置於更廣的 hopfion 文獻脈絡中**，包括 Faddeev-Niemi 結孤立子 [18]（v0.7 的「而非一般性的電磁結」一語，低估了 [8–10] 早已包含的拓撲內容）
2. **提出氣泡環類比**作為物理直覺——將電磁環比擬為潛水員的氣泡環
3. **提出觀測到的球形是透過自身光暈觀看的厚發光環面，其圓形外觀不依賴旋轉**，現已附上定量幾何約束（附錄A）。球狀閃電的環形模型早於本工作——Johnson 的環形場模型（1965）[48]、Koloc 的 PLASMAK（位於近球形電漿殼內的環形電流環）[49]、Seward 提出旋轉的環看起來像球（1997）[50]，以及 [11] 的鏈結環狀流束——而環狀或環面形的球狀閃電偶有報告 [47]。此處的貢獻在於特定的幾何機制及其經量化、可檢驗的推論，而非環面本身（v0.7 稱之為「原創性的觀測預測」）
4. **連結至近年（2015–2023）凝態物質、光學與 BEC 系統中的 hopfion 觀測** [28–34]，以及數值 MHD 研究 [27]，這些在 Ranada-Trueba 模型提出時尚不存在
5. **明確陳述模型的定量自洽性問題**（第6A、8A章）

其他基礎貢獻包括 **Kamchatnov-Hopf 拓撲 MHD 孤立子**（1982）[26]，透過 Hopf 映射構造精確孤立子解；以及 **Smiet 等人的 MHD 模擬**（2015）[27]，展示了電阻性電漿中自組織的結狀磁結構。最接近的實驗室電漿類比是**球馬克** [38]。
